# 中洲史诗《指环王 / 魔戒》电影百科 V1.1 典藏修正版

## 文件内容
- index.html：HTML 多媒体电子书版。
- 中洲史诗_指环王魔戒电影百科_V1.1_豪华图文版.pdf：PDF 豪华图文版，适合收藏和打印。
- appendices：人物关系图、中洲阅读地图、电影时间线。
- assets：正文插图素材。
- media/original_middle_earth_ambient_v11.wav：原创离线氛围曲。

## 本版修正
1. 音乐控制台改为正文内嵌，不再悬浮锁定，不遮挡阅读。
2. 页面不再打开即自动播放音乐，避免与播放器冲突。
3. 经典主题曲不下载完整音频，改为第三方平台内嵌搜索入口。
4. 主界面增加图文导览卡片、场景图、人物关系图、阅读地图和时间线。

## 使用方法
双击或在手机文件中打开 index.html 即可浏览。在线音乐受第三方平台和网络环境影响；无网时可使用原创离线氛围曲。
